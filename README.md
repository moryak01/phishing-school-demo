# Простой учебный сервис проверки URL на признаки фишинга

Это демонстрационный проект для школы/обучения.

Сервис анализирует введенную ссылку только с помощью простых эвристических правил:
- нет HTTPS;
- используется IP-адрес;
- слишком длинный URL;
- много поддоменов;
- есть символ `@`;
- есть подозрительные слова;
- есть похожие на известные бренды опечатки;
- используются подозрительные доменные зоны;
- есть punycode/нестандартные символы.

Проект **не делает запросы на проверяемые сайты**, не загружает страницы,
не выполняет JavaScript и не собирает историю проверок.
